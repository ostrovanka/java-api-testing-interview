## REST API Testing Interview Task

Interview task for a Senior SDET position.

The repository contains two implementations of the same API test suite against [restful-api.dev](https://api.restful-api.dev/objects):

### Java (TestNG + RestAssured)

```bash
cd java
mvn test
```

### TypeScript (Mocha + Axios + Chai)

```bash
cd typescript
npm install
npm test
```
